# SpendWise – Personal Expense Tracker

SpendWise is an offline-first personal spending tracker built with Flutter. It helps users manage their income, expenses, and monthly budgets through a simple and user-friendly interface.

## Internship Project – Week 2

This project was developed as part of **Week 2 of my Mobile App Development Internship at Stack and Scale**.

The task focuses on building a personal expense tracker using Flutter, with features for transaction management, monthly budgeting, financial calculations, and offline data storage.

Through this project, I am gaining practical experience in Flutter development, Dart programming, UI design, state management, and local database integration.

## Features

- **Dashboard:** View monthly income, expenses, remaining budget, and recent transactions.
- **Transaction Management:** Add and edit income and expense transactions.
- **Transaction History:** View and manage recorded transactions.
- **Monthly Budgets:** Create and edit budgets for different expense categories.
- **Budget Tracking:** Monitor spending against category limits.
- **Search:** Search and explore transactions.
- **Offline Storage:** Store app data locally for offline use.
- **Category Management:** Organize transactions by category.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android emulator or physical Android device

### Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd spendwise
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
